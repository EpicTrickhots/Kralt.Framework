# Kralt.Framework

Kralt.Framework is a C# rendering library built with OpenGL via the [OpenTK](https://github.com/opentk/opentk) library.

## Goals for This Project

- Support for high-performance 3D games, as well as light-weight desktop applications with zero unnecessary engine bloat.
- Full cross-platform functionality for Windows, MacOS, and Linux.
- Flexbox-based UI system inspired by Unity's [UIToolkit](https://docs.unity3d.com/6000.2/Documentation/Manual/UIElements.html).
    

## Applications built on Kralt.Framework

None of these projects exist
-   **Kralt** - The base game
-   **Kralt.Editor** - A standalone editor for creating custom Kralt levels.
-   **Kralt.Launcher** - A launcher for installing, managing Kralt applications.
-   **Kralt.Mixer** - Audio workstation for creating looping custom Kralt songs.
- **Kralt.Explorer** - Kralt-based replacement for Windows file explorer.
- **KraltOS** - Kralt operating system. (All Kralt applications are installed natively and cannot be deleted)
